# Troop artwork

`logos.webp` is a transparent two-cell header sprite: Nexus left, Orion right.
`goelands.webp` is the standalone blue/black Goélands pennant.
`patrols.webp` is a transparent five-cell sprite: Lions, Guépards, Orcs, Renards, Taureaux.

These are cleaned renderings made with the image tool from images supplied by the user, retaining the source colours. They are not byte-for-byte original photographic files. The Renards animal is obscured in the supplied photo; the user explicitly requested retaining its visible dark folded pennant. No fox was invented.

Production files use WebP encoding for smaller mobile downloads. Original generated PNGs remain in /workspace/generated_images.
